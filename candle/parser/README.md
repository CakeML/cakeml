The parser for Candle's OCaml-like syntax, written in CakeML. `cake --candle`
loads `candle_boot.cml`, which is this directory's parser sources followed by
`candle_glue.cml`; Candle input then reaches the verified REPL as parsed
declarations. The parser is a port of the definitions in
`compiler/parsing/ocaml`.

[candle_boot.cml](candle_boot.cml):
Candle REPL startup, generated by gen_candle_boot.sh from the parser
sources and candle_glue.cml.

[candle_glue.cml](candle_glue.cml):
Candle REPL startup after the parser: CakeML-syntax bindings that the
Candle prelude needs, error reporting for CandleParser, and the switch to
reading candle_boot.ml through CandleParser.

[conversion_support.cml](conversion_support.cml):
Conversion helpers from camlPtreeConversionScript.sml. All errors are
values. Choice is left-biased and evaluates its alternative only on failure.

[declarations.cml](declarations.cml):
Candle declaration lowering from camlPtreeConversionScript.sml. Embedded
CakeML pragmas are reported as unsupported.

[expression_support.cml](expression_support.cml):
Expression lowering helpers from camlPtreeConversionScript.sml. Ast.Ident is
the runtime spelling of HOL's Var.

[expressions.cml](expressions.cml):
The mutually recursive ptree_Expr family from camlPtreeConversionScript.sml.
check_tokens sequences expect_tok calls; expr_binary shares the identical
binary-tier clauses, keeping the reference's evaluation order.

[front_end.cml](front_end.cml):
The caml_parser entry point up to, but not including, AST conversion.

[grammar.cml](grammar.cml):
The camlPEG rule table, with choice and list order unchanged. Each original
nonterminal nFoo is called NFoo here.

[grammar_support.cml](grammar_support.cml):
Grammar-building helpers of camlPEG, with native string predicates.

[lexer.cml](lexer.cml):
The lexer, ported from compiler/parsing/ocaml/caml_lexScript.sml.

[names.cml](names.cml):
Name and operator conversion, keeping the reference's error strings and
compatibility renamings. Node checks precede child conversion.

[parser.cml](parser.cml):
CandleParser.parse, the string entry point of caml_parser.run: Ast
declarations or a located error, with no I/O or state.

[patterns.cml](patterns.cml):
Pre-patterns, precedence resolution, compatibility currying and pattern
conversion from camlPtreeConversionScript.sml, including its record
restrictions and or-pattern distribution.

[peg.cml](peg.cml):
PEG execution, ported from pegexec.coreloop. The continuation machine keeps
backtracking, error-stack order and list-tail sharing as in the reference.

[precedence.cml](precedence.cml):
Operator-precedence resolution, ported from precparser's precparse1 and
precparse.

[support.cml](support.cml):
Parser locations and list helpers, ported from HOL's location theory and
CakeML's lexer_fun.

[tokens.cml](tokens.cml):
Token vocabulary and reserved spellings, ported from caml_lexScript.sml.

[tree.cml](tree.cml):
Parse trees from grammar.ptree, restricted to token leaves: the executable
grammar never builds a nonterminal leaf. Nonterminal names keep the
reference's sum shape.

[type_declarations.cml](type_declarations.cml):
Type and constructor metadata and exception declarations, ported from
camlPtreeConversionScript.sml. Metadata keeps source field order; the
preparation helpers below perform the reference's reordering. Record
functions are generated by the declaration layer.

[types.cml](types.cml):
Types and literals, ported from camlPtreeConversionScript.sml.
