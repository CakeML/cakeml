The parser for Candle's OCaml-like syntax, written in CakeML. `cake --candle`
loads `candle_boot.cml`, which is this directory's parser sources followed by
`candle_glue.cml`; Candle input then reaches the verified REPL as parsed
declarations. The parser is a port of the HOL definitions formerly in
`compiler/parsing/ocaml`, which remain available in the git history
(`git log -- compiler/parsing/ocaml`).

[candle_boot.cml](candle_boot.cml):
Candle REPL startup, generated by gen_candle_boot.sh from the parser
sources and candle_glue.cml.

[candle_glue.cml](candle_glue.cml):
Candle REPL startup after the parser: CakeML-syntax bindings that the
Candle prelude needs, error reporting for CandleParser, and the switch to
reading candle_boot.ml through CandleParser.

[conversion_support.cml](conversion_support.cml):
Parse-tree conversion helpers. All errors are values. Choice is left-biased
and evaluates its alternative only on failure.

[declarations.cml](declarations.cml):
Candle declaration lowering. Embedded CakeML pragmas are reported as
unsupported.

[expression_support.cml](expression_support.cml):
Expression lowering helpers. Ast.Ident is the runtime spelling of HOL's
Var.

[expressions.cml](expressions.cml):
The mutually recursive ptree_Expr family, converting expression parse
trees. check_tokens sequences expect_tok calls; expr_binary shares the
identical binary-tier clauses and their evaluation order.

[front_end.cml](front_end.cml):
The parser front end: lexing and parsing up to, but not including, AST
conversion.

[grammar.cml](grammar.cml):
The PEG rule table of Candle's grammar, one rule per nonterminal NFoo.
Choices are tried in the order listed.

[grammar_support.cml](grammar_support.cml):
Grammar-building helpers for the PEG rule table, with native string
predicates.

[lexer.cml](lexer.cml):
The lexer for Candle's syntax.

[names.cml](names.cml):
Name and operator conversion, with its error strings and compatibility
renamings. Node checks precede child conversion.

[parser.cml](parser.cml):
CandleParser.parse, the string entry point of the parser: Ast declarations
or a located error, with no I/O or state.

[patterns.cml](patterns.cml):
Pre-patterns, precedence resolution, compatibility currying and pattern
conversion, including record restrictions and or-pattern distribution.

[peg.cml](peg.cml):
PEG execution as a continuation machine, with backtracking and tracking of
the furthest error.

[precedence.cml](precedence.cml):
Operator-precedence resolution: shift/reduce over a stack of operators and
operands.

[support.cml](support.cml):
Parser locations, and list, character and digit helpers.

[tokens.cml](tokens.cml):
Token vocabulary and reserved spellings of Candle's syntax.

[tree.cml](tree.cml):
Parse trees from grammar.ptree, restricted to token leaves: the executable
grammar never builds a nonterminal leaf. Node labels have the
('b,int) sum shape of grammar.ptree's nonterminals.

[type_declarations.cml](type_declarations.cml):
Type and constructor metadata and exception declarations. Metadata keeps
source field order; the preparation helpers below sort each record's fields
by name. Record functions are generated by the declaration layer.

[types.cml](types.cml):
Conversion of types and literals from parse trees.
