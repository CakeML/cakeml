This directory contains scripts that compile the fused CakeML compiler
inside the logic to produce verified arm8 machine code.

[arm8BootstrapScript.sml](arm8BootstrapScript.sml):
Evaluation of the fused compiler into arm8 machine code.

[basis_ffi.c](basis_ffi.c):
Implements the foreign function interface (FFI) used in the CakeML basis
library, as a thin wrapper around the relevant system calls.

[candle_boot.cml](candle_boot.cml):
Candle REPL startup, generated by gen_candle_boot.sh from the parser
sources and candle_glue.cml.

[hello.cml](hello.cml):
A simple hello world program in CakeML

[proofs](proofs):
This directory contains the end-to-end correctness theorem for the
fused CakeML compiler compiled to arm8 machine code.

[repl_boot.cml](repl_boot.cml):
This file gives the CakeML REPL multi-line input and file loading
capabilities.

[test-hello.cml](test-hello.cml):
A hello world program used for testing that the bootstrapped
compiler was built successfully.
